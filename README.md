# wtmp-hopchain

여러 서버의 `last` / `wtmp` 로그만으로 **다단계 SSH 점프(A → B → C → D)와 역순 SFTP 회수(C←D, B←C, A←B)** 를
시간 순서표로 재구성하는 단일 HTML 뷰어입니다.

설치·서버·인터넷 없이 `hopviewer.html` 을 브라우저로 열기만 하면 됩니다. 로그는 브라우저 밖으로 나가지 않습니다.

## 무엇을 찾나

```
A 로그인 → A→B → B→C → C→D 점프
D 에서 exit → C→D 재접속(sftp 로 파일 가져오기)
C 에서 exit → B→C 재접속(sftp)
B 에서 exit → A→B 재접속(sftp) → A 로그아웃
```

A 에서 B 로 들어간 세션은 B 의 wtmp 에 남고, 그 세션이 살아 있는 동안 B→C, C→D 접속이 일어납니다.
그래서 **다음 서버 세션의 [로그인 ~ 로그아웃] 이 앞 서버 세션 안에 들어가면** 둘을 부모-자식으로 잇습니다.
계정명은 보지 않고 시간만 봅니다.

- 같은 부모 세션 아래에서 **먼저 들어간 세션이 끝난 뒤(exit) 다시 생긴 세션** → "재접속 — 파일 가져오기(sftp) 추정"
- 재접속이 깊은 서버부터 D→C, C→B, B→A 순서로 이어지면 → **역순 회수 패턴**
- 시간상 들어갈 수 있는 앞 서버 세션이 여러 개면 가장 늦게 시작한(가장 촘촘한) 세션을 부모로 고르고 `후보 N` 으로 표시

## 사용법

1. `hopviewer.html` 을 브라우저(Chrome·Edge·Firefox)로 엽니다. 처음이면 **예시 데이터** 로 동작을 확인하세요.
2. 서버 칸 A·B·C·D 에 **접속 순서대로** 각 서버의 로그를 끌어다 놓거나 붙여넣습니다. (`+ 서버 추가` 로 최대 8대)
3. **접속 체인 · 타임테이블** 화면에서 왼쪽 체인을 고르면(↑↓ 키) 오른쪽에 간트 그래프, 패턴 체크, 시간 순서표가 나옵니다.
   순서표는 복사하거나 CSV 로 저장할 수 있습니다.

### 넣을 수 있는 로그

| 형식 | 예 |
|---|---|
| `last` 기본 출력 | `root  pts/0  10.0.0.5  Sat Oct  3 09:05 - 11:20  (02:14)` |
| `last -F` (초·연도 포함, 권장) | `... Sat Oct  3 09:05:30 2026 - Sat Oct  3 11:20:05 2026  (02:14)` |
| 날짜 숫자 표기 | `2026-10-03 09:05 - 11:20 (02:14)`, `2026/10/03 ...`, `10/03 ...` |
| `last --time-format iso` | `2026-10-03T09:05:30+09:00 - ...` |
| `last -a` (출발지가 줄 끝) | `root  pts/0  Sat Oct  3 09:05 - 11:20  (02:14)  10.0.0.5` |
| wtmp 바이너리 | `/var/log/wtmp`, `wtmp.1`, `wtmp.1.gz` |

서버에서 뽑을 때 권장 명령:

```bash
last -F -i -f /var/log/wtmp > $(hostname)_last.txt
```

`/var/log/lastlog` 는 계정별 마지막 1회 로그인만 있어 쓸 수 없습니다. `btmp` 는 실패 기록이라 대상이 아닙니다.

## 옵션

- **허용 오차(초)**: `last` 기본 출력은 분 단위라 기본 60초. 초 단위 로그면 줄여도 됩니다.
- **시간 보정(초)**: 서버마다 시계가 다르면 칸별로 더할 값을 넣습니다. (예: B 시계가 90초 빠르면 `-90`)
- **연도**: 연도 없는 출력은 `wtmp begins` 줄 → 요일 순으로 추정합니다. 틀리면 칸에 직접 적으세요.
- **서버 IP**: 채우면 다음 서버 로그의 출발지와 비교해 IP 일치/불일치를 표시합니다.
  `출발지 IP 일치만` 을 켜면 시간만 우연히 겹친 세션을 걸러냅니다.
  칸 아래에 시간이 맞는 출발지 IP 가 제안되며, 누르면 바로 들어갑니다.
- **표시 시간대**: wtmp 바이너리와 ISO(시간대 포함) 시각을 이 시간대로 바꿔 보여줍니다.

## 한계

- `last` 기본 출력은 시각이 분 단위로 잘려 있어 1~2분 어긋날 수 있습니다. 가능하면 `last -F` 나 wtmp 원본을 쓰세요.
- sftp/scp 는 pty 를 쓰지 않아 OS·sshd 설정에 따라 **wtmp 에 아예 안 남거나** tty 가 `pts/N` 이 아닌 값으로 남습니다.
  회수 세션이 안 보이면 `auth.log` / `secure` 의 `subsystem request for sftp` 를 같이 확인하세요.
- 시간 겹침만으로 판정하므로 같은 시간대에 다른 사람이 접속했다면 잘못 이어질 수 있습니다. 서버 IP 를 채우면 줄어듭니다.

## 성능

서버당 세션 50,000개 × 4대를 약 0.7초에 분석합니다. 시작 시각 정렬과 구간 최대값 트리로 짝을 찾아 세션당 O(log n) 입니다.
화면에는 체인 120개, 순서표 1,500행, 세션 표 1,000행까지만 그리고, 복사·CSV 에는 전부 들어갑니다.
